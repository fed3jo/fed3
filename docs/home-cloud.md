# السحابة المحلية

صفحتا `/ar/home-cloud/` و`/en/home-cloud/` تعرضان فكرة خادم مستقل داخل المؤسسة، ومسار الملفات، وخطوات التجهيز والتدريب، والنسخ الاحتياطي والصيانة. الشريط العائم يربط بأقسام الصفحة نفسها: الفكرة، وكيف تعمل، وخطوات التجهيز، والجاهزية.

## المراجع

- [Next Cloud Report.docx](https://drive.google.com/file/d/1s8PKg_V0FvNptVeIMAJ91htGaFnu8BIY/view)، ضمن مجلد المبادرة. استُخدم تسلسل التجهيز والحسابات والنسخ والاستعادة والتسليم. التقرير يناقش الاستخدام المنزلي، بينما نموذج الجاهزية يحدد المؤسسات والمراكز المجتمعية جمهورًا للمحطة. لا تنشر الصفحة مواصفات أو تكلفة أو موعد تركيب غير معتمد.
- [نموذج تقييم وجاهزية البنية التحتية الموازية Home-cloud](https://docs.google.com/forms/d/1ZXW8EavCbdDq6Eh9MBe0o-Xmdi5gEBkqsfVopRm48mo/preview)، داخل «مخرجات الاسبوع 12». قُرئت الأسئلة في وضع المعاينة دون إرسال استجابة. تُعرض الأسئلة الـ13 وخياراتها في ثلاث مجموعات، مع تصحيح لغوي وترجمة إنجليزية.
- [Nextcloud All-in-One](https://github.com/nextcloud/all-in-one#readme)، و[دليل النسخ الاحتياطي](https://docs.nextcloud.com/server/latest/admin_manual/maintenance/backup.html)، و[إدارة المستخدمين](https://docs.nextcloud.com/server/latest/admin_manual/configuration_user/user_configuration.html). راجعت الصفحة هذه المراجع في 25 أكتوبر 2026. روابط الأدلة متاحة بجانب خطوات التجهيز.

## معاينة الاستبيان

يمكن التنقل بين الأقسام وتجربة الاختيارات وخيار «أخرى». تحتفظ حالة React بالإجابات أثناء وجود المكوّن في الصفحة، وتزول عند تحديث الصفحة أو مغادرتها. لا يستخدم الاستبيان التخزين المحلي أو ملفات تعريف الارتباط، ولا يكتب إلى Drive أو Google Forms أو أي واجهة إرسال. يمنع معالج النموذج الإرسال، وزر الإرسال معطّل وموسوم «الإرسال قريبًا».

الأسئلة لا تنتج درجة جاهزية أو قبولًا للتجهيز، ولا تمثل اتفاقًا أو تسجيل طلب. تشغيل الإرسال يحتاج عملًا مستقلًا عند اعتماد استقبال الردود.

## التحقق

تغطي `tests/home-cloud.browser.spec.ts` الروابط المحلية وأوضاع الوصول والخطوات الست، ومعاينة جميع الأسئلة، وبقاء الإجابات أثناء التنقل وزوالها عند التحديث، وغياب طلبات الإرسال، واللغتين وعروض الموبايل. تشمل الفحوص أيضًا حذف قسم السردية العام وتجميع بطاقات المشهد مع شعارات التطبيقات، وتبديل مجموعات معلومات التطبيق.
