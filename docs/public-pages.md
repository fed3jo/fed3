# صفحات التعريف والتواصل والخصوصية

تاريخ المحتوى: 16 تشرين الثاني 2026.

- المسارات: `/ar/about/` و`/ar/contact/` و`/ar/privacy/`، مع نسخ إنجليزية تحت `/en/`.
- المصدر الحالي للتعريف: وصف المبادرة المنشور بالموقع ووثائق المبادرة المتصلة في Drive. بعض الوثائق القديمة تتضمن تواريخ تنفيذ مختلفة؛ لا تمثل جدول تسجيل حاليًا.
- أكد المستخدم البريد العام `Fed3JoR@proton.me`، وأن التسجيل الجديد والشهادات والساعات التطوعية قريبًا. لم يقدّم تواريخ أو شروطًا أو جهة إصدار للشهادة.
- لا تُنشر أسماء شركاء أو تفاصيل اعتماد غير مؤكدة. وصف الفريق يقتصر على متطوعي برنامج اليافعين في مؤسسة رواد التنمية بعمّان، كما في التعريف الحالي.
- لا تجمع هذه التعديلات أحداث استخدام أو طلبات تسجيل. الاستبيان يظل معاينة في ذاكرة الصفحة، والبريد يفتح تطبيق المستخدم.
- سياسة الخصوصية وصف للتشغيل الحالي. عند إضافة قاعدة البيانات أو الإحصاءات أو خدمة وسائط خارجية، يجب مراجعتها حسب الإعداد الحقيقي قبل تشغيل الجمع، بما فيه الحقول والمزوّد والاحتفاظ والتحكّم.
- بيانات التواصل وعناوين الصفحات وأوصافها في `lib/fed3/public-info.ts`، والصفحات في `components/info/InfoPage.tsx`.
