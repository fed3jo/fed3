# مقارنة البدائل

تعرض صفحة البدائل لوحة بصرية للتطبيق الحالي والبديل. يظهر شعار كل تطبيق واسمه في عمود مستقل. تفتح أداة تغيير التطبيق قائمة بتصميم الموقع تضم الشعارات والأسماء، وتدعم الإغلاق بـEscape أو النقر خارجها. يستخدم عمود البديل الكحلي، ويستخدم عمود التطبيق الحالي خلفية فاتحة، مع الحفاظ على الألوان الأصلية للشعارات.

المحاور العشرة موزعة على أربعة أقسام:

| القسم | المحاور |
| --- | --- |
| الخصوصية والبيانات | التشفير، معالجة البيانات، الإعلانات، مكان البيانات، الحساب |
| المزايا والأجهزة | الوظائف اليومية، الأجهزة المدعومة |
| التكلفة | التكلفة |
| الانتقال والقيود | التصدير والانتقال، الحدود والمسؤولية |

تختار التبويبات الأربعة مجال المقارنة، وتختار الأزرار المختصرة تحته النقطة المعروضة، مثل التشفير أو التكلفة. تبدأ المقارنة بمجال الخصوصية وبنقطة مناسبة للتطبيق: البيانات لـSignal، وحظر الإعلانات لـBrave، والتشفير لـProton Mail، والتحكم بالملفات لـNextcloud، والحساب لـONLYOFFICE. الروابط التي تحدد نقطة بعينها تحافظ عليها. تعرض اللوحة نقطة واحدة كل مرة، وتدعم التبويبات أسهم لوحة المفاتيح وHome وEnd.

تظهر المعلومتان جنبًا إلى جنب على الكمبيوتر والهاتف، بمحاذاة عمودَي التطبيقين، مع سؤال وأيقونة يوضحان موضوع النقطة. لكل محور ملخص بلغة مبسطة في `comparison-briefs.ts`، يتضمن هايلايت للفكرة المهمة. تبقى الشروط المؤثرة واضحة، ويظهر النص الكامل الأصلي مع مصادره في التفاصيل القابلة للتوسيع. لا تضيف اللوحة درجات أمان أو نسبًا للتطبيقات. تستخدم مقارنات صفحات التطبيقات الملخصات نفسها.

يظهر زر التنزيل داخل بطاقة البديل وفي نهاية المقارنة، ويفتح صفحة الناشر الرسمية لاختيار نسخة الجهاز. يتضمن `app-start.ts` وصفًا مبسطًا وفائدة وخطوة بداية وثلاث تعليمات قصيرة لكل تطبيق، مع توضيح الحاجة لحساب سحابة جاهز عند استخدام عميل Nextcloud. رابط صفحة التطبيق يفتح التعليمات التفصيلية، وتظهر ملاحظات المقارنة وتاريخ مراجعة المصادر داخل قسم قابل للتوسيع.

روابط البداية روجعت في 15 نوفمبر 2026: [Signal](https://signal.org/download/)، [Brave](https://brave.com/download/)، [Proton Mail](https://proton.me/mail/download)، [Nextcloud](https://nextcloud.com/install/)، [ONLYOFFICE](https://www.onlyoffice.com/desktop).

تحدد معلمة `app` التطبيق، وتحدد `group` التبويب (`privacy` أو `features` أو `cost` أو `migration`)، وتحدد `criterion` النقطة المعروضة. يحفظ نسخ الرابط وتبديل اللغة الحالة نفسها. تعود القيم غير المعروفة والروابط القديمة التي تتضمن `group=none` إلى الخصوصية. تستمر روابط `view=privacy` في فتح مقارنة الخصوصية، وتُحدّث الصيغة عند التفاعل.
