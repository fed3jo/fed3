# مقارنة البدائل

تعرض صفحة البدائل لوحة بصرية للتطبيق الحالي والبديل. يظهر شعار كل تطبيق واسمه في عمود مستقل، مع قائمة لتغيير التطبيق. يستخدم عمود البديل الكحلي، ويستخدم عمود التطبيق الحالي خلفية فاتحة، مع الحفاظ على الألوان الأصلية للشعارات.

المحاور العشرة موزعة على أربعة أقسام:

| القسم | المحاور |
| --- | --- |
| الخصوصية والبيانات | التشفير، معالجة البيانات، الإعلانات، مكان البيانات، الحساب |
| المزايا والأجهزة | الوظائف اليومية، الأجهزة المدعومة |
| التكلفة | التكلفة |
| الانتقال والقيود | التصدير والانتقال، الحدود والمسؤولية |

تختار التبويبات الأربعة مجال المقارنة، وتختار الأزرار المختصرة تحته النقطة المعروضة، مثل التشفير أو التكلفة. تبدأ المقارنة بالخصوصية والتشفير افتراضيًا. تعرض اللوحة نقطة واحدة كل مرة، وتدعم التبويبات أسهم لوحة المفاتيح وHome وEnd.

تظهر المعلومتان جنبًا إلى جنب على الكمبيوتر والهاتف، بمحاذاة عمودَي التطبيقين، مع سؤال وأيقونة يوضحان موضوع النقطة. الهايلايت يحيط بمقتطفات من النص الأصلي ويشمل القيود والشروط. لا تضيف اللوحة درجات أمان أو نسبًا للتطبيقات. تظهر مصادر النقطة المعروضة داخل تفاصيل قابلة للتوسيع.

في النهاية، يظهر ملخص المكاسب وما يحتاج المستخدم معرفته، وخطوة البداية مع رابط الناشر. رابط صفحة التطبيق يفتح التعليمات والمعلومات التفصيلية. تظهر ملاحظات قراءة المقارنة وتاريخ مراجعة المصادر داخل قسم قابل للتوسيع.

تحدد معلمة `app` التطبيق، وتحدد `group` التبويب (`privacy` أو `features` أو `cost` أو `migration`)، وتحدد `criterion` النقطة المعروضة. يحفظ نسخ الرابط وتبديل اللغة الحالة نفسها. تعود القيم غير المعروفة والروابط القديمة التي تتضمن `group=none` إلى الخصوصية. تستمر روابط `view=privacy` في فتح مقارنة الخصوصية، وتُحدّث الصيغة عند التفاعل.
