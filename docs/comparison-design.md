# مقارنة البدائل

تعرض صفحة البدائل مقارنة واحدة للتطبيق الحالي والبديل. يظهر الزوج في شريط يبقى أسفل الهيدر أثناء قراءة المقارنة، مع قائمة لتغيير التطبيق.

المحاور العشرة موزعة على أربعة أقسام:

| القسم | المحاور |
| --- | --- |
| الخصوصية والبيانات | التشفير، معالجة البيانات، الإعلانات، مكان البيانات، الحساب |
| المزايا والأجهزة | الوظائف اليومية، الأجهزة المدعومة |
| التكلفة | التكلفة |
| الانتقال والقيود | التصدير والانتقال، الحدود والمسؤولية |

يفتح قسم الخصوصية افتراضيًا. يمكن فتح قسم واحد أو إغلاق الأقسام كلها. تبقى نقطة الاختيار ظاهرة تحت شريط التطبيقين عند تغير ارتفاع المحتوى.

تعرض كل نقطة النص الأصلي للتطبيقين جنبًا إلى جنب على الكمبيوتر، وتحت بعضهما على الهاتف. الهايلايت يحيط بمقتطفات محددة من النص نفسه، ويشمل القيود والشروط. لا يضيف درجات أمان أو تصنيفًا للتطبيقات. تظهر مصادر كل نقطة داخل تفاصيل قابلة للتوسيع.

في النهاية، يظهر ملخص المكاسب وما يحتاج المستخدم معرفته، وخطوة البداية مع رابط الناشر. رابط صفحة التطبيق يفتح التعليمات والمعلومات التفصيلية. تظهر ملاحظات قراءة المقارنة وتاريخ مراجعة المصادر داخل قسم قابل للتوسيع.

تحدد معلمة `app` التطبيق، وتحدد `group` القسم المفتوح (`privacy` أو `features` أو `cost` أو `migration` أو `none`). يحفظ نسخ الرابط وتبديل اللغة الحالة نفسها. الروابط السابقة التي تتضمن `view=privacy` تفتح المقارنة بقسم الخصوصية، وتُحدّث الصيغة عند التفاعل.
